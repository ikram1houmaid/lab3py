# Lab 3 – Opérations, Comparaisons et Logique booléenne

## Présentation

Ce laboratoire a pour objectif de découvrir et de pratiquer les différents opérateurs du langage Python : les opérations arithmétiques, les comparaisons et la logique booléenne.

Il permet également de réaliser un mini-projet pratique de calcul de réduction sur le prix d'un produit.

## Exercices réalisés

### Exercice 1 : Opérations arithmétiques
Fichier : `lab3_operations.py`

Utilisation des opérateurs arithmétiques :
- Addition (+)
- Soustraction (-)
- Multiplication (*)
- Division (/)
- Division entière (//)
- Modulo (%)
- Puissance (**)

### Exercice 2 : Comparaisons
Fichier : `lab3_comparaisons.py`

Utilisation des opérateurs de comparaison :
- Égalité (==)
- Différence (!=)
- Inférieur (<)
- Supérieur (>)
- Inférieur ou égal (<=)
- Supérieur ou égal (>=)

### Exercice 3 : Logique booléenne
Fichier : `lab3_logique.py`

Utilisation des opérateurs logiques :
- AND : vérifie si deux conditions sont vraies.
- OR : vérifie si au moins une condition est vraie.
- NOT : inverse une valeur booléenne.

### Exercice 4 : Mini-projet – Calcul de réduction
Fichier : `mini_reduction.py`

Réalisation d'un programme qui calcule le prix final d'un produit selon plusieurs conditions :

- Réduction de 10 % pour les étudiants.
- Réduction de 15 % pour les clients ayant au moins 5 ans de fidélité.
- Réduction supplémentaire de 5 € pour les produits dont le prix dépasse 100 €.
- Vérification des saisies utilisateur.
- Protection contre les prix négatifs.

## Technologies utilisées

- Langage : Python 3
- Éditeur : Visual Studio Code

## Exécution

Chaque exercice peut être exécuté séparément depuis le terminal :

```bash
python lab3_operations.py
python lab3_comparaisons.py
python lab3_logique.py
python mini_reduction.py
```
